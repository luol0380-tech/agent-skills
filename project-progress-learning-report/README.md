# 项目进度与学习验收汇报

适用于项目整体进度、阶段交付与用户验收汇报。根据实际文件、代码和测试证据，按六部分说明项目进展、产品功能、技术架构、本期工作与学习点、测试验收以及下一步行动。

默认模板由 `config/current_template.txt` 指定。需要选择其他模板时，运行 `python3 scripts/select_template.py --list` 查看可用名称，再使用 `--template <名称>`；此操作不会改动默认值。

项目私有资料与个人表达偏好留在本地，不放入公开模板。运行仓库根目录的 `python3 scripts/audit_repository.py` 可检查结构、模板切换及常见隐私泄露。
