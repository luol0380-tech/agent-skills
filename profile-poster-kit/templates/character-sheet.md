# Character Model Sheet

## Format

Create one wide character sheet containing:

1. Four full-body views: front, three-quarter, side, and back.
2. Four facial expressions relevant to the role.
3. A detail area for stable accessories and clothing construction.
4. Five color swatches.
5. One title using the supplied display name.

Use a neutral pose and empty hands for turnaround views. Include no biography, scenery, or unsupplied labels. Preserve the approved face, proportions, hair, clothing silhouette, detail placement, palette, shoes, and accessories.

## Example

Input: `Use the approved poster character. Preserve short wavy hair, round glasses, a navy jacket, cream shirt, straight trousers, and brown shoes.`

Expected result: four consistent views, four expressions, clothing/accessory details, five swatches, and no change to the approved identity or costume.
