# Profile Poster

## Format

Create one vertical profile poster containing:

1. Optional series label supplied by the user.
2. Role subtitle.
3. Large horizontal display name.
4. Only the populated identity groups, in the supplied order.
5. One full-body or three-quarter character that preserves the portrait identity.
6. Background and decoration from local brand configuration when available.

Before delivery, inspect exact text, mobile readability, face identity, adult anatomy, hands, feet, clothing, and unauthorized additions.

## Example

Input: `Portrait supplied locally. Display name: [Name]. Role: Community facilitator. Biography: Parent of two; leads weekend workshops; organizes peer learning.`

Expected result: one vertical poster with the verified role and three biography lines, a consistent adult character, no invented credential, and no organization mark unless supplied in private assets.
