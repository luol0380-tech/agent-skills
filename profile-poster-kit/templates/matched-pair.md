# Matched Poster and Character Sheet

## Format

1. Lock verified identity text and visual invariants.
2. Produce and approve the profile poster using the supplied portrait and local brand configuration.
3. Produce the character sheet from the approved poster character.
4. Compare the pair side by side for face, age impression, body ratio, hair, glasses, clothing silhouette, detail placement, colors, shoes, and accessories.
5. Deliver both images plus a short list of locked cues and retained text groups.

Reject the pair if either image changes the person's identity, facts, clothing system, or adult proportions.

## Example

Input: `Create both outputs from a portrait and three verified biography lines. Use a restrained editorial style from the local brand file.`

Expected result: approve the poster first, derive the model sheet from that approved character, then deliver two matching images with a concise consistency note.
