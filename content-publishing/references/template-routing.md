# Article template routing

Track `writing_template`, `cover_template`, and `layout_template`, each `ai-practice` or `family-growth`. Explicit user choice wins. Otherwise classify the central subject: practical AI work versus family life and personal growth. If still ambiguous, ask one focused question. Default all three to the selected template, and preserve selections in later turns.

Priority: latest user instruction > approved reference for that component > local private profile > generic template. An example title, identity, date, column label or number is not reusable copy. A cover-only change must not change text, layout or ending. A layout-only change must not change the writing template's closing rules.

Record the approved title/text and component selections before packaging. Preserve approved font, symbols, palette, composition and wording. Modify only requested parts. Never invent missing branding.

Optional private files: `private/brand-profile.md`, `private/personal-style.md`, `private/approved-references.md`, `private/assets/`. Keep real cases and reference images local. Public export must use reviewed text-file allowlists and exclude all private content, images and credentials. Git ignore rules do not remove files already tracked or present in history.
