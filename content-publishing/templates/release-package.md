# Release Package

## Format

```markdown
## Recommended title
[title]

## Alternative titles
1. [alternative]
2. [alternative]

## Cover copy
- Headline: [headline]
- Subtitle: [subtitle]
- Label: [series or category, if supplied]

## Share description
[one curiosity-led description]

## Asset order
1. [asset filename] — Purpose: [claim or transition it supports]

## Final checks
- [ ] Facts verified
- [ ] Sensitive data removed or blurred
- [ ] Prototype status stated accurately
- [ ] External write not performed without confirmation
```

Do not add a fixed slogan, series name, or visual identity unless supplied through private configuration or the current request.

## Example

Input: `Package the approved article about a two-week planning experiment. Use the supplied cover and two evidence screenshots.`

Expected package: one recommended title, up to two alternatives, concise cover copy, a non-duplicative share description, ordered filenames with purpose, and a completed privacy/status checklist.
